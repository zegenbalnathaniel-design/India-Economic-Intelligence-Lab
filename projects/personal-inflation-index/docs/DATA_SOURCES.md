# Data Sources

This project ships **no real official CPI data**. This sandbox has no
internet access to MoSPI's publications, and fabricating numbers that
look official would be far worse than being upfront that they don't
exist here. This document does two things: (1) tells you exactly where
to get the real data if you want to use this toolkit for anything beyond
a methodology demonstration, and (2) labels the status of every data
file actually bundled with this repository.

## Where to get the real data

| Field | Detail |
|---|---|
| **Source** | Consumer Price Index (CPI), All-India and State/UT level |
| **Provider** | Ministry of Statistics and Programme Implementation (MoSPI), Government of India |
| **URL** | https://mospi.gov.in/ (see the CPI section for monthly press releases and the current base-year linking factor documentation) |
| **Definition** | A monthly index measuring the average change in prices paid by consumers for a representative basket of goods and services, published for Rural, Urban, and Combined sectors, and broken into sub-groups (Food and beverages, Housing, Fuel and light, Clothing and footwear, Miscellaneous, etc.) |
| **Unit** | Index points, base year = 2012 as of the most recent base revision at time of writing — **confirm the current base year directly from MoSPI**, as base years are periodically revised |
| **Frequency** | Monthly |
| **Date coverage** | Published series extend from the base year to the current month, with a roughly 4-6 week publication lag |
| **Transformations needed to use with this toolkit** | Map MoSPI's published sub-group index values onto this project's category names (they will not align one-to-one — MoSPI's structure is more granular and uses different group boundaries than this project's 9 illustrative categories), and extract the MoSPI-published combined weights for each sub-group (from the base-year linking/weight documentation) to use as `weights` in place of `EXAMPLE_ILLUSTRATIVE_WEIGHTS` |
| **Limitations** | MoSPI's category weights are themselves a national-average household expenditure survey snapshot taken at the base year — the same basket-staleness and substitution-bias caveats discussed in `docs/METHODOLOGY.md` apply to the official series itself, not just to this toolkit's demonstration |

| Field | Detail |
|---|---|
| **Source** | Household Consumption Expenditure Survey (HCES) |
| **Provider** | MoSPI / National Sample Survey Office (NSSO) |
| **URL** | https://mospi.gov.in/ (survey reports section) |
| **Definition** | Periodic household-level survey of consumption expenditure by category, used (among other things) as the basis for CPI basket weights and for studying expenditure patterns across income groups, states, and urban/rural areas |
| **Unit** | Rupees of monthly/annual household expenditure by category, survey-weighted |
| **Frequency** | Irregular (large rounds roughly once a decade historically, with more frequent recent releases) |
| **Date coverage** | Varies by survey round — check the latest release for current coverage |
| **Transformations needed to use with this toolkit** | Aggregate reported item-level expenditure into this project's category buckets (or your own, finer buckets) and compute each category's share of total household expenditure to use as `weights` |
| **Limitations** | Self-reported expenditure surveys carry recall bias and sampling error; large survey rounds are infrequent, so weights derived from them age between rounds (the basket-staleness issue discussed in `docs/METHODOLOGY.md`) |

**If you use real MoSPI/NSSO figures with this toolkit:** treat any
specific number you recall or find (a weight, a sub-group index value)
as **"commonly reported, requires independent verification against the
current MoSPI publication before being treated as precise"** unless you
have the primary document open in front of you. Base years, category
definitions, and weights are periodically revised, and numbers that were
correct for one base year are not automatically correct for another.

## Status of every data file actually bundled with this project

| File | Status |
|---|---|
| `data/synthetic_category_price_index.csv` | **100% synthetic.** Generated by `examples/generate_synthetic_data.py` from a fixed random seed (`20240601`) using simple random-walk-with-drift simulation per category. Contains no real price observations. Regenerate it any time by re-running that script — output is deterministic. |
| `src/personal_inflation/example_data.py` (`EXAMPLE_ILLUSTRATIVE_WEIGHTS`) | **Illustrative placeholder weights only.** Hand-picked round numbers loosely shaped like commonly reported CPI category splits (food largest, then housing, etc.), explicitly **not** MoSPI's published weights. Meant to be overridden by the user. |
| The `official_cpi_reference` column inside the synthetic CSV | **Not a real CPI series.** It is a weighted blend of the synthetic category columns in the same file, using the illustrative weights above, used only to give the comparison feature (`compare_to_reference`) and the Streamlit app something to plot against. |
| Any weights or prices you enter yourself into the Streamlit app, a notebook, or directly into the Python functions | **Whatever you tell it.** This toolkit performs no validation that your inputs match any particular real-world source — that responsibility is yours, and the point of the tool is to let you plug in numbers you trust. |

## The short version

Everything bundled here is clearly either (a) a deterministic synthetic
demo series, or (b) an illustrative placeholder weight set. If you want a
real personal-inflation estimate, pull your own category weights from
your own budget (most accurate) or from the real MoSPI/NSSO sources
above (verified against the current publication), and your own observed
prices or the real MoSPI CPI sub-group series for comparison, and feed
those into the functions in `src/personal_inflation/index.py` in place of
the bundled examples.

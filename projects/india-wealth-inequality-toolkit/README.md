# India Wealth Inequality Toolkit

A small, dependency-light Python toolkit for income and wealth inequality measurement (Gini, Lorenz curve, percentile shares, Palma ratio, concentration ratios), plus a deterministic household wealth-composition simulator.

## Research Question

How do standard inequality statistics behave on real-world-shaped distributions, and — separately — how much of long-run household wealth divergence can be explained by *asset allocation* rather than *income*, holding savings behaviour fixed?

## Why I Built This

Public debate about Indian inequality mostly cites a small number of headline Gini or top-1%-share figures without showing how they're computed or how sensitive they are to measurement choices. I wanted a toolkit where every statistic is a transparent, tested function — not a black box — and a companion simulator that makes a specific mechanism (composition effect) explorable rather than asserted.

## Economic Theory

- **Gini coefficient / Lorenz curve**: standard measures of distributional concentration, widely used in World Bank, World Inequality Lab and NSSO/PLFS-adjacent literature.
- **Palma ratio**: motivated by Palma's (2011) observation that the share held by the "stable middle" (roughly deciles 5-9) is remarkably constant across countries and over time, so cross-country/time variation in inequality is concentrated in the tails — hence a measure built only from the top 10% and bottom 40%.
- **Composition effect**: if household wealth `W_t = Σ_k w_k · B_{k,t}` and asset classes `k` earn persistently different returns `r_k`, then two households with identical savings behavior can diverge in wealth purely from `w` (allocation), independent of income. This is a mechanical, not a causal, claim — see Limitations.

## Data

This toolkit does not ship or fabricate real inequality survey data. `data/synthetic_household_wealth.csv` is a clearly-labelled **synthetic** dataset (lognormal body + Pareto tail) generated by `examples/generate_synthetic_wealth.py` for demonstration only. Point the toolkit at your own CSV for real analysis — see [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) for where defensible Indian income/wealth distribution data can be obtained.

## Results / Demonstration

Running the toolkit against the bundled synthetic file produces a Gini coefficient, Lorenz curve, and percentile shares for that *synthetic* distribution only — these numbers describe the synthetic generator, not India. See the Streamlit app for an interactive walkthrough, and `notebooks/01_inequality_measures_demo.ipynb` for a scripted walkthrough.

## How It Works

```
src/india_inequality/
├── inequality.py   # calculate_gini, lorenz_curve, percentile_share, palma_ratio, concentration_ratio
└── wealth.py        # composition_effect, monte_carlo, rminusg_frame
```

Every function takes plain arrays/dicts in and returns plain arrays/DataFrames out — no hidden global state, no network calls.

## Usage

```python
from india_inequality import calculate_gini, lorenz_curve, palma_ratio
import pandas as pd

df = pd.read_csv("data/synthetic_household_wealth.csv")
values = df["net_worth_inr_lakhs"]

print(calculate_gini(values))
print(palma_ratio(values))
curve = lorenz_curve(values)
```

## Limitations

- Gini/Lorenz/percentile-share formulas here assume **non-negative** values; household *net worth* can be negative (more debt than assets), which these formulas do not handle without an explicit convention — the toolkit raises rather than silently producing a misleading number.
- Top-tail wealth is systematically underreported in most household surveys (the very rich are undersampled and underreport); no statistical correction for this is applied here.
- The composition-effect simulator is **deterministic** — it shows the mechanical implication of fixed returns and a fixed allocation, not a prediction. Historical asset-class returns are not guaranteed to persist.
- Inequality of outcomes (income/wealth) is distinct from inequality of opportunity; this toolkit measures only the former.
- A single summary statistic (Gini, Palma) necessarily discards information relative to the full distribution — always look at the Lorenz curve too.

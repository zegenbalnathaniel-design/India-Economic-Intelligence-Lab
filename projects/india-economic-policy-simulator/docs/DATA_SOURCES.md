# Data Sources

## Macro simulator (`macro_model.py`)

No external data is used. `CalibrationParams` defaults are **illustrative calibration choices** loosely consistent with publicly reported aggregate ratios — e.g. a marginal propensity to consume in the 0.65-0.75 range, a proportional tax-rate-like parameter near India's general-government tax-to-GDP ratio, and a debt-to-GDP starting point near India's general-government level as reported by the RBI/IMF. These are **not** estimated from Indian time series by any statistical procedure, and are not sourced from a single dataset — treat every default as "a reasonable order of magnitude for a teaching model," not as an official statistic.

## Empirical module (`monetary_transmission.py`, `data/processed/`)

| Dataset | Status | Source | Notes |
|---|---|---|---|
| `bank_panel.csv` | **Illustrative / synthetic** | Generated by `src/policy_simulator/build_illustrative_data.py`, seed=42 | Five Indian banks, quarterly, 2018-Q2 to 2024-Q3. Levels are loosely shaped around publicly reported ranges for the five indicators, but values are **not** taken from any single bank's actual disclosures. |
| `repo_rate.csv` | **Approximate** | Hand-entered from the qualitative RBI MPC decision history | Rounded quarter-end values intended to track the real repo-rate path's shape; replace with the RBI-published series (below) for a genuine empirical result. |

## Where to get the real series

| Source | Provider | What it has | URL |
|---|---|---|---|
| Database on Indian Economy (DBIE) | Reserve Bank of India | Repo rate history, monetary policy decisions | https://dbie.rbi.org.in |
| Basel III Pillar 3 disclosures | Individual banks | CET1, LCR, NCO by bank, quarterly | Each bank's investor-relations site |
| Annual reports / quarterly results | Individual banks | PPNR, unrealised AFS losses | Each bank's investor-relations site |

## Provenance conventions

Every CSV in this repo carries a `source`/`provenance` designation of one of: `official`, `derived`, `illustrative`. `bank_panel.csv` and `repo_rate.csv` are both `illustrative` in this build — replace them with `official` values sourced as above to turn the empirical module's output into a genuine empirical finding.
